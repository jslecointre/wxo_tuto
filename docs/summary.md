# Synthèse

Vous savez maintenant concevoir, construire et déployer des agents IA avec watsonx Orchestrate, sans code comme en pro-code.

## Ce que vous savez faire

| Compétence | Valeur |
| :--- | :--- |
| **Orchestrer plusieurs agents** | Confier une tâche complexe à des agents spécialisés qui partagent le contexte et s'appellent entre eux |
| **Réutiliser l'existant** | Partir des agents prédéfinis du catalogue plutôt que de tout construire |
| **Construire sans code** | Créer agents, bases de connaissances et workflows agentiques dans le navigateur, en quelques minutes |
| **Atteindre les utilisateurs là où ils sont** | Exposer un agent sur WhatsApp ou d'autres canaux |
| **Industrialiser avec l'ADK** | Versionner agents et workflows en code, les importer et les tester depuis la ligne de commande ou avec Bob |
