## Présentation

Un tutoriel pratique pour les développeurs qui veulent découvrir ce que propose IBM watsonx Orchestrate et apprendre à l'utiliser.
Ce parcours d'apprentissage peut être suivi sur IBM Developer
[Get started with watsonx Orchestrate](https://developer.ibm.com/learningpaths/get-started-watsonx-orchestrate/prebuilt-domain-agents/).

Vous allez :

- Définir ce qu'est l'orchestration d'agents IA.
- Comprendre les architectures courantes, les fonctionnalités clés, les termes et les concepts de watsonx Orchestrate.
- Voir à quoi ressemble une orchestration multi-agents en pratique.
- Développer des systèmes multi-agents sans code et les exposer sur d'autres canaux.
- Configurer un environnement local pour l'Agent Development Kit (ADK) de watsonx Orchestrate.
- Construire un agent en pro-code avec l'ADK, à l'aide de Bob.

/// tip | Prérequis
Une instance watsonx Orchestrate. Un [essai gratuit de 30 jours](https://www.ibm.com/account/reg/us-en/signup?formid=urx-54418){target="_blank" rel="noopener"} suffit (il faut un [IBMid](https://www.ibm.com/account/reg/us-en/signup?formid=urx-19776){target="_blank" rel="noopener"}).
